=============================================================
THE HAWTHORN TREE ACUPUNCTURE CLINIC — STANDALONE WEBSITE
=============================================================

This package contains the pure, lightweight website for Maureen Murphy's
clinic in Gort, Co. Galway, built with standard HTML, CSS, and JavaScript.

CONTENTS:
-------------------------------------------------------------
- index.html        : The complete website page (pure HTML5)
- style.css         : The stylesheet with all typography, colors, and responsive layout
- script.js         : The interactive logic (mobile menu, FAQ accordion, booking form)
- images/
    - blackboyandme.jpg    : Photo of Maureen and her dog Blackboy
    - hawthorn-ink.jpg     : Traditional ink-wash hawthorn botanical art
    - burren-landscape.jpg : The Burren karst limestone landscape

HOW TO USE:
-------------------------------------------------------------
1. Offline / Desktop:
   Simply double-click "index.html" to open the website directly in any web browser
   (Google Chrome, Safari, Firefox, Microsoft Edge). No server or npm needed.

2. Web Hosting / Deployment:
   You can upload these files and the "images" folder directly to any web host:
   - cPanel / Apache / Nginx / Shared Hosting (drop in public_html)
   - Netlify, Vercel, or Cloudflare Pages (drag-and-drop the folder)
   - GitHub Pages
   - Or embed into any standard website builder without frameworks.

3. Replacing the Portrait Photo:
   If you want to use the ai pic of 'you', simply swap the filenames
   "blackboyandme.jpg" and place it into the "images" folder to overwrite it.
